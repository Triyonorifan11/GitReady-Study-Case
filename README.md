# GitReady Study Case — Tampilan Web Sederhana BNCC

Proyek ini adalah tampilan web sederhana untuk BNCC, dibangun menggunakan HTML, CSS, dan JavaScript murni (vanilla) tanpa framework atau build tool tambahan. Proyek ini juga menjadi studi kasus kolaborasi tim menggunakan Git & GitHub.

🔗 Repository: [GitReady-Study-Case](https://github.com/Triyonorifan11/GitReady-Study-Case)

## Tech Stack

- **HTML5** — struktur halaman
- **CSS3** — styling tampilan
- **JavaScript (ES6+)** — interaktivitas
- **Git & GitHub** — version control dan kolaborasi tim

Tidak ada dependency atau package manager yang diperlukan.

### Struktur Proyek

```
.
├── index.html   # Halaman utama
├── style.css    # Styling tampilan
├── script.js    # Logika/interaktivitas
└── README.md    # Dokumentasi proyek
```

### Cara Menjalankan

1. Clone repository ini.
2. Buka file `index.html` langsung di browser (double click, atau klik kanan → Open with Browser).
3. Opsional: gunakan ekstensi [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) di VS Code untuk auto-reload saat development.

- Kerangka halaman utama BNCC (`index.html`)
