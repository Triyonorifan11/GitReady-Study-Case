# Tampilan Web Sederhana BNCC

Proyek ini adalah tampilan web sederhana untuk BNCC, dibangun menggunakan HTML, CSS, dan JavaScript murni (vanilla) tanpa framework atau build tool tambahan.

## Status Proyek

🚧 Masih tahap awal (skeleton). `index.html` adalah kerangka utama, sedangkan `style.css` untuk styling tampilan web dan `script.js` untuk logical dari web ini.

## Struktur Proyek

```
.
├── index.html   # Halaman utama
├── style.css    # Styling tampilan
├── script.js    # Logika/interaktivitas
└── README.md    # Dokumentasi proyek
```

## Cara Menjalankan

Karena proyek ini tidak memerlukan build tool, kamu bisa langsung menjalankannya di browser:

1. Clone atau download repository ini.
2. Buka file `index.html` langsung di browser (double click, atau klik kanan → Open with Browser).

Opsional, untuk pengalaman development yang lebih nyaman (auto-reload saat file diubah), gunakan ekstensi **Live Server** di VS Code:

1. Install ekstensi [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) di VS Code.
2. Klik kanan pada `index.html` → **Open with Live Server**.

## Teknologi yang Digunakan

- **HTML5** — struktur halaman
- **CSS3** — styling tampilan
- **JavaScript (ES6+)** — interaktivitas

Tidak ada dependency atau package manager yang diperlukan.
